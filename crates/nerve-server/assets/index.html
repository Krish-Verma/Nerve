Nerve

The read-only evidence API is running on this loopback address. The explorer interface is not part of this build yet.

What is here

  • GET /api/overview — counts, unresolved totals, last run, schema, freshness
  • GET /api/search?q=&kind=&limit= — full-text symbol search
  • GET /api/entity?selector= — one entity, its occurrences, its defining edges
  • GET /api/neighbourhood?selector=&depth=&max_nodes= — a bounded graph
  • GET /api/path?from=&to= — how two entities are connected
  • GET /api/why?subject=&object= — the evidence packet, with freshness
  • GET /api/source?path=&start_line=&end_line= — a bounded source snippet
  • GET /api/unresolved — what Nerve could not resolve
  • GET /api/partial-parses — which files parsed with errors

Every request needs the session token

Send it as the X-Nerve-Token header, or as a token query parameter. It is printed once by nerve serve and is never written to disk. Requests from another origin are refused, and so is any Host that is not this loopback address.

Nothing here can change anything

The API is read-only. It performs no network access, sends no telemetry, and serves file contents only for paths that are already in the index, resolved through the same path guard the indexer uses.
